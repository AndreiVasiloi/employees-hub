# Step 9: Write Information Architecture Document

## Objective

Write the complete IA document to `explore/design/information-architecture-[slug].md`.

## Entry Criteria

- [ ] Step 8 (Open Questions) complete with human confirmation

## Actions

### 9.1 Write Document

Write complete IA document to `explore/design/information-architecture-[slug].md`.

**Use template**: `templates/ia-template.md`

**Required sections**:
1. Snapshot (Objective, Scope, Users, Surfaces, Assumptions, Constraints)
2. Organizing Principles (Primary strategy, Supporting principles, Trade-offs)
3. Navigation Model (Proposed model, Rationale, Behavior rules)
4. Sitemap or Screen Hierarchy (Complete hierarchy with notes)
5. Content Model Alignment (Key entities, Relationships, Governance)
6. Labeling and Taxonomy (Section labels, Screen labels, Controlled vocabulary, Facets)
7. Entry Points and Wayfinding (Primary/secondary entry points, Deep linking, Location awareness)
8. Roles and Permissions Impact (Roles, What changes by role)
9. Open Questions and Validation Plan (Questions, Validation methods)
10. Decisions Log (Key decisions with rationale)
11. Acceptance Criteria (Checklist)

### 9.2 Verify Document

Confirm the file contains all 11 sections with no placeholder text remaining.

## Exit Criteria

- [ ] Document written to `explore/design/information-architecture-[slug].md`
- [ ] All 11 sections present and populated
- [ ] No placeholder text remaining
