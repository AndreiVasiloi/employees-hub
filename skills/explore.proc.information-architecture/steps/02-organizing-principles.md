# Step 2: Define Organizing Principles

## Objective

Propose the primary grouping strategy that best supports top tasks and user mental models.

## Entry Criteria

- [ ] Step 1 (Top Tasks) complete with human confirmation

## Actions

### 2.1 Propose Grouping Strategy

```
Organizing Principles

Based on the top tasks, I recommend organizing the information architecture using:

**Primary grouping strategy**: [Goal-based / Entity-based / Lifecycle-based / Responsibility-based]

**Rationale**: [Why this strategy best supports the top tasks and user mental models]

**Supporting principles**:
- Keep hierarchy shallow (2-4 levels max)
- Prioritize primary tasks over internal org structure
- Use consistent, plain-language labels
- Separate operational/admin areas from day-to-day work
- Prefer progressive disclosure over deep nesting

**Trade-offs**:
- Optimizes for: [What this structure prioritizes]
- May sacrifice: [What this structure deprioritizes]

Does this organizing strategy align with your vision? Any adjustments needed?
```

**STOP**: Wait for human to validate organizing principles.

## Exit Criteria

- [ ] Primary grouping strategy selected with rationale
- [ ] Supporting principles documented
- [ ] Trade-offs explicitly stated
- [ ] Human has validated organizing principles
