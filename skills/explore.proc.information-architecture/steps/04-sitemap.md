# Step 4: Create Sitemap or Screen Hierarchy

## Objective

Build the complete hierarchy based on top tasks, organizing strategy, and navigation model.

## Entry Criteria

- [ ] Step 3 (Navigation Model) complete with human validation

## Actions

### 4.1 Gather Section List

```
Sitemap / Screen Hierarchy

I'll now create the full sitemap based on:
- Top tasks: [List]
- Organizing strategy: [Strategy]
- Navigation model: [Model]

Please provide:
1. List of all major sections/features to include
2. Any specific screens or views you know are needed
3. Role-based areas (if applicable)
```

**STOP**: Wait for human to provide section list.

### 4.2 Create Detailed Hierarchy

After receiving section list, create detailed hierarchy as ASCII tree structure:

```
Detailed Sitemap

[Create ASCII tree structure showing all levels]

Notes:
- Max depth: [N] levels
- Global vs contextual: [What is always available vs entity-scoped]
- Naming conventions: [Singular vs plural, verb vs noun]

Review this hierarchy. Does it support all top tasks? Any sections missing or misplaced?
```

**STOP**: Wait for human to validate hierarchy.

## Exit Criteria

- [ ] Complete sitemap created as ASCII tree
- [ ] Depth limits documented with rationale
- [ ] Global vs contextual sections identified
- [ ] Naming conventions established
- [ ] Human has validated hierarchy
