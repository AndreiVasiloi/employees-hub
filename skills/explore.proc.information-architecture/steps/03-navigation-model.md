# Step 3: Propose Navigation Model

## Objective

Select and justify a navigation model based on organizing principles.

## Entry Criteria

- [ ] Step 2 (Organizing Principles) complete with human validation

## Actions

### 3.1 Propose Navigation Model

```
Navigation Model Proposal

**Recommended model**: [Side navigation / Tabs / Hub-and-spoke / Search-first / Linear flow]

**Rationale**:
- [Why this model fits the tasks]
- [Why this model fits the scale]
- [Why this model fits the constraints]

**Behavior rules**:

Persistent navigation:
- [What stays visible across all screens]

Contextual navigation:
- [What changes based on selected entity, role, or state]

Breadcrumbs:
- [Yes/No and where used]

Search:
- Scope: [Global / Section / Entity]
- Index: [What content is searchable]
- Results grouping: [By entity / type / date / etc.]

Cross-links:
- [Rules for linking between related areas]

Does this navigation model work for your needs?
```

**STOP**: Wait for human to validate navigation model.

## Exit Criteria

- [ ] Navigation model selected with rationale
- [ ] Behavior rules defined (persistent, contextual, breadcrumbs, search, cross-links)
- [ ] Human has validated navigation model
