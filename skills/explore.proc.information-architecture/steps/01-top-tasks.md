# Step 1: Review Inputs and Identify Top Tasks

## Objective

Review personas, journeys, and flows to identify the 3-5 most important tasks users need to complete. These tasks drive all navigation and hierarchy decisions.

## Entry Criteria

- [ ] Context baseline available (domain model, system map)
- [ ] Personas available
- [ ] Journey maps available
- [ ] User flows available (or will be created alongside)
- [ ] Slug confirmed

## Actions

### 1.1 Review Discovery Artifacts

Review personas, journey maps, and user flows to understand:
- Who the users are and what they need
- What tasks they perform most frequently
- Where current friction exists

### 1.2 Identify Top Tasks

```
Top Tasks Identification

Based on the personas and journey maps, what are the 3-5 most important tasks users need to complete?

List them in priority order:
1. [Task 1] - [Which persona(s)]
2. [Task 2] - [Which persona(s)]
3. [Task 3] - [Which persona(s)]
4. [Task 4] - [Which persona(s)]
5. [Task 5] - [Which persona(s)]

These tasks will drive the navigation model and hierarchy decisions.
```

**STOP**: Wait for human to confirm top tasks.

## Exit Criteria

- [ ] 3-5 top tasks identified and prioritized
- [ ] Each task linked to persona(s)
- [ ] Human has confirmed top tasks
