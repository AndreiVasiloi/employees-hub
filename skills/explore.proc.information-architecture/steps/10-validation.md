# Step 10: Validation

## Objective

Run a completeness check on the information architecture document.

## Entry Criteria

- [ ] Step 9 (Write Document) complete
- [ ] Document exists at `explore/design/information-architecture-[slug].md`

## Actions

### 10.1 Run Completeness Check

Verify all required elements:

- [ ] Navigation model is selected and justified
- [ ] Sitemap or hierarchy covers the full defined scope
- [ ] Labels are consistent and supported by controlled vocabulary
- [ ] Entry points and wayfinding rules are defined
- [ ] Role or permission impacts are explicit where relevant
- [ ] Open questions and validation plan are prioritized and actionable
- [ ] Top tasks can be completed using the proposed structure
- [ ] Hierarchy depth is appropriate (2-4 levels)
- [ ] All sections have clear, plain-language labels

### 10.2 Present Validation Results

```
Information Architecture Complete

File: explore/design/information-architecture-[slug].md
Sections: [N] major sections
Max depth: [N] levels
Roles: [N] roles with differentiated access
Open questions: [N] prioritized for validation

Top tasks supported:
✓ [Task 1]
✓ [Task 2]
✓ [Task 3]

Ready for wireframing and prototyping.
```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Document ready for downstream consumption
