# Step 7: Define Non-Negotiables

## Objective

List requirements that MUST be met before launch and cannot be compromised, deferred, or worked around.

## Entry Criteria

- [ ] Step 6 (Risk Register) complete

## Actions

### 7.1 Define Non-Negotiables by Category

For each non-negotiable requirement, document:
- Why it is non-negotiable
- Consequence if missed
- Validation method
- Owner

**Categories**:
- **Legal non-negotiables** (e.g., privacy policy before data collection)
- **Data protection non-negotiables** (e.g., encryption at rest)
- **Accessibility non-negotiables** (e.g., keyboard accessibility)
- **Security non-negotiables** (e.g., MFA for admin accounts)
- **Disclosure non-negotiables** (e.g., ToS accepted before account creation)
- **Evidence non-negotiables** (e.g., audit logging with timestamps)

### 7.2 Confirm Launch Blockers

These requirements block launch if not met and validated.

## Exit Criteria

- [ ] Non-negotiables defined per category
- [ ] Each has consequence, validation method, and owner
- [ ] Launch blockers clearly identified
