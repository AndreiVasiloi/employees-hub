# Step 3: Establish Accessibility Requirement Baseline

## Objective

Define accessibility obligations including applicable standards, legal requirements, baseline requirements, and testing needs.

## Entry Criteria

- [ ] Step 2 (Data Handling) complete

## Actions

### 3.1 Identify Applicable Standards

- WCAG level (2.1 AA, 2.2 AA, AAA)
- Section 508 (if US government)
- EN 301 549 (if EU)
- Other regional standards

### 3.2 Document Legal Obligations

Per jurisdiction:
- What the law requires
- Penalties for non-compliance
- Deadlines

### 3.3 Define Baseline Requirements

- Keyboard accessibility
- Screen reader support
- Color contrast ratios
- Text alternatives
- Responsive and adaptable design

### 3.4 Document Exemptions (if any)

- What is exempt and why
- Alternative access methods provided

### 3.5 Define Testing Requirements

- Automated testing (tools, frequency)
- Manual keyboard testing
- Screen reader testing
- User testing with people with disabilities

### 3.6 Documentation Requirements

- Accessibility statement content and location
- VPAT/ACR requirements

See Accessibility Specifications skill for detailed implementation.

## Exit Criteria

- [ ] Applicable standards identified with levels
- [ ] Legal obligations documented per jurisdiction
- [ ] Baseline requirements defined
- [ ] Testing requirements specified
- [ ] Documentation requirements listed
