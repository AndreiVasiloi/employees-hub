# Step 2: Define Data Handling Rules

## Objective

Document how data must be collected, stored, accessed, and managed to comply with identified regulations.

## Entry Criteria

- [ ] Step 1 (Applicable Standards) complete

## Actions

### 2.1 Data Collection Rules

- What data can be collected and legal basis
- Consent requirements (when, how, granularity)
- Minimum age requirements
- Purpose limitation
- Data minimization

### 2.2 Data Retention Rules

- Retention periods by data type
- Deletion requirements (automatic, user-requested)
- Right to erasure and exceptions
- Archival requirements

### 2.3 Data Access and Portability

- User access rights and methods
- Data export requirements (formats, methods)
- Third-party access rules and legal basis

### 2.4 Data Security

- Encryption requirements (at rest, in transit)
- Access controls and authentication
- Breach notification timelines and process
- Audit logging requirements

### 2.5 Cross-Border Data Transfers

- Transfer mechanisms (SCCs, adequacy, BCRs)
- Approved and prohibited countries
- Data localization requirements

## Exit Criteria

- [ ] Data collection rules documented with legal basis
- [ ] Retention periods defined by data type
- [ ] Access and portability rules specified
- [ ] Security requirements documented
- [ ] Cross-border transfer rules defined
