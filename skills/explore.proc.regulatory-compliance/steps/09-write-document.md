# Step 9: Write Regulatory and Compliance Document

## Objective

Write the complete regulatory and compliance document to `explore/explore-[slug]/regulatory-compliance.md`.

## Entry Criteria

- [ ] Step 8 (Acceptance Criteria) complete

## Actions

### 9.1 Write Document

Write complete document to `explore/explore-[slug]/regulatory-compliance.md`.

**Use template**: `templates/regulatory-compliance-template.md`

**Required sections**:
1. Applicable Standards and Policies (by region, industry, data type)
2. Data Handling Rules (collection, retention, access, security, transfers)
3. Accessibility Requirements (standards, obligations, baseline, testing)
4. Copy and Disclosure Requirements (disclosures, consent, notices, warnings)
5. Evidence Requirements (audit logs, confirmations, proof, retention)
6. Compliance Risk Register (risks with likelihood, impact, mitigation)
7. Non-Negotiables List (requirements that cannot be compromised)
8. Compliance Acceptance Criteria (testable criteria by area)

### 9.2 Verify Document

Confirm all 8 sections present with no placeholder text remaining.

## Exit Criteria

- [ ] Document written to `explore/explore-[slug]/regulatory-compliance.md`
- [ ] All 8 sections present and populated
- [ ] No placeholder text remaining
- [ ] All requirements tagged with owner and validation method
