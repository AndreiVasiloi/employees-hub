# Step 10: Validation

## Objective

Run a completeness check on the regulatory and compliance document.

## Entry Criteria

- [ ] Step 9 (Write Document) complete
- [ ] Document exists at `explore/explore-[slug]/regulatory-compliance.md`

## Actions

### 10.1 Run Completeness Check

Verify all required elements:

- [ ] Applicable regulations identified by region and industry
- [ ] Data handling rules documented (collection, retention, security)
- [ ] Accessibility requirements baseline established
- [ ] Copy and disclosure requirements specified
- [ ] Evidence requirements documented (logs, records, proof)
- [ ] Compliance risk register created with mitigation strategies
- [ ] Non-negotiables list clearly defined
- [ ] Compliance acceptance criteria generated
- [ ] All requirements tagged with owner and validation method

### 10.2 Present Validation Results

```
Regulatory and Compliance Analysis Complete

File: explore/explore-[slug]/regulatory-compliance.md
Regulations identified: [N] regulations across [N] regions
Non-negotiables: [N] requirements
Compliance risks: [N] high priority, [N] medium priority
Acceptance criteria: [N] testable criteria

Ready for legal review and compliance validation.
```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Document ready for legal review
