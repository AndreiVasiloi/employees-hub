## 8. Compliance Acceptance Criteria

**Purpose**: Create testable acceptance criteria for QA validation and definition of done.

### Data Collection and Consent

- [ ] Privacy policy displayed before any data collection
- [ ] Privacy policy linked in footer on all pages
- [ ] Consent mechanism allows granular choices (e.g., separate checkboxes for different data uses)
- [ ] Consent can be withdrawn at any time via settings page
- [ ] Consent records include timestamp, user ID, consent type, and policy version
- [ ] Users under {age} cannot create accounts (age gate implemented)
- [ ] Parental consent obtained for users under {age} (if applicable)

---

### Data Retention and Deletion

- [ ] Data retention periods enforced automatically (e.g., cron job deletes expired data)
- [ ] Users can request data deletion via settings page
- [ ] Data deletion completes within {X} days of request
- [ ] Data deletion is logged (timestamp, user ID, data deleted)
- [ ] Deletion is verifiable (data cannot be recovered)
- [ ] Exceptions to deletion are documented (e.g., legal hold, fraud prevention)

---

### Data Security

- [ ] All personal data encrypted at rest (AES-256 or equivalent)
- [ ] All data encrypted in transit (TLS 1.3 or 1.2 minimum)
- [ ] Access controls enforce least privilege (users have minimum necessary access)
- [ ] MFA required for admin accounts
- [ ] Security audit logs retained for {X} years
- [ ] Breach detection mechanisms in place (intrusion detection, anomaly detection)
- [ ] Breach notification process documented and tested

---

### Accessibility

- [ ] All functionality accessible via keyboard (no mouse required)
- [ ] No keyboard traps (user can navigate away from all elements)
- [ ] Focus indicators visible on all interactive elements
- [ ] Screen reader announces all interactive elements with meaningful labels
- [ ] Color contrast meets WCAG 2.2 AA (4.5:1 for text, 3:1 for UI components)
- [ ] All images have alt text (decorative images have empty alt)
- [ ] All form inputs have accessible labels
- [ ] Error messages are announced by screen readers

---
