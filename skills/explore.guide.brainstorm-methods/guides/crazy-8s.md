# Method: Crazy 8s (text variant)

**Primitives used:** `generate(flexibility)` with time pressure simulation
**Best for:** Quick divergence, breaking analysis paralysis, warming up before deep work
**Cognitive mode:** Pure flexibility, speed over quality

## Protocol

1. State the problem in one sentence
2. Generate 8 distinct ideas in rapid succession
3. Rules:
   - Each idea must be different from the previous ones (not a variant)
   - One-liner per idea (force compression)
   - No evaluation — just production
   - Aim for diversity of approach, not quality
4. After all 8: quick review — which 2-3 are worth developing further?

## Persistence Follow-up

After Crazy 8s, pick the 2 most interesting and do a "Crazy 4" variant on each — 4 variations of the same idea using `transform` operators.
