# Method: Affinity Mapping + Impact-Effort

**Primitives used:** `cluster`, `evaluate`, `select`
**Best for:** Post-divergence convergence, making sense of a large idea set
**Cognitive mode:** Convergence — structure and decide

## Protocol

1. **Affinity clustering:**
   - Read all ideas
   - Group by natural themes (not quality)
   - Name each group with a thesis, not just a topic
   - Flag outliers and bridges

2. **Impact-Effort scoring:**
   - For each cluster (not individual ideas): rate Impact (H/M/L) and Effort (H/M/L)
   - Plot on 2x2:
     - **Quick Wins** (H impact, L effort): Priority 1
     - **Big Bets** (H impact, H effort): Investigate and validate
     - **Fill-ins** (L impact, L effort): Nice to have
     - **Drops** (L impact, H effort): Don't pursue

3. **Output:** Clusters with thesis labels + 2x2 placement + prioritized action list
