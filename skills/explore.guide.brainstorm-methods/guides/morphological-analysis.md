# Method: Morphological Analysis

**Primitives used:** `decompose` (primary), `generate`, `evaluate`
**Best for:** Complex systems with multiple independent parameters, product architecture, strategy design, configuration spaces
**Cognitive mode:** Persistence — systematic enumeration and combination

## Protocol

1. **Decompose** the problem into 4-7 independent parameters
   - Ask: "What are the fundamental dimensions that define a solution in this space?"
   - Each parameter should be genuinely independent

2. **Enumerate** 3-6 values for each parameter
   - Include the conventional/default value
   - Include at least one unconventional or extreme value
   - Include a "zero" or "eliminate" value where possible

3. **Build the morphological box** (markdown table)

4. **Generate configurations:**
   - 3 conventional configurations (sanity baseline)
   - 3 "forced unusual" configurations (randomly combine uncommon values)
   - 3 "themed" configurations (pick a theme like "minimal," "maximal," "inverted" and select coherent values)

5. **Consistency cross-check:** For each configuration, flag impossible or contradictory combinations. Remove truly impossible ones. Keep "uncomfortable but possible" ones.

6. **Narrate** each viable configuration as a one-paragraph concept

## Expected Output

Morphological table + 6-9 narrated configurations + evaluation notes.
