# Method: Synectics / Bisociation

**Primitives used:** `associate(far)`, `blend` (primary)
**Best for:** Breakthrough innovation, cross-domain transfer, "nothing in our industry does this" problems
**Cognitive mode:** Flexibility → Blend → Persistence

## Protocol

1. **State the problem's core tension** in abstract terms
   - Strip away domain specifics: "We need to [verb] [abstract object] under [constraint]"

2. **Pick 2-3 remote domains** using one of these selection methods:
   - Random: biology, music, military, cooking, sports, astronomy, theater
   - Structural: "what other domain faces the same structural challenge?"
   - Personal: "what from your hobby/life handles something like this?"

3. **Explore each domain:**
   - How does this domain solve the abstracted problem?
   - What mechanisms, materials, or principles does it use?
   - What's surprising about its approach?

4. **Map back to the original domain:**
   - Which mechanisms transfer?
   - What would the "biology version" of our product look like?
   - What emergent properties appear when we blend these domains?

5. **Construct 3-5 blended concepts** using the `blend` protocol from Cognitive Primitives skill

**Key insight:** Don't just borrow surface features ("gamification" is lazy synectics). Look for deep structural analogies — principles and mechanisms, not aesthetics.
