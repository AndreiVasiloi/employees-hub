# Method: Reverse Brainstorming

**Primitives used:** `reframe(invert)`, `generate`, `transform(reverse)`
**Best for:** When normal brainstorming produces bland results, preventing something, finding failure modes
**Cognitive mode:** Inversion — flexibility through negation

## Protocol

1. Invert the problem: "How could we make [problem] as bad as possible?" or "How could we guarantee [undesired outcome]?"
2. Brainstorm 10-15 ways to cause the problem (be creative about failure)
3. For each failure cause, invert it into a solution:
   - "Cause: make the interface confusing → Solution: progressive disclosure with contextual guidance"
4. The inversions often reveal non-obvious solutions because failure modes highlight assumptions you weren't examining

## Expected Output

Failure causes list + inverted solutions + top candidates.
