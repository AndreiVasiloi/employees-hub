# Method: TRIZ (Lite)

**Primitives used:** `reframe(contradiction)`, `transform`, `associate(structural)`
**Best for:** Technical problems with inherent contradictions, engineering tradeoffs, "we can't have both X and Y" problems
**Cognitive mode:** Persistence — structured contradiction resolution

## Lite Protocol (without the full 40-principle matrix)

1. **State the contradiction:** "We need [parameter A] to be [value] BUT that causes [parameter B] to be [undesirable value]"

2. **Identify contradiction type:**
   - Technical: improving one parameter worsens another
   - Physical: same parameter needs to be in two states simultaneously

3. **Apply separation principles:**
   - In time: can A be true sometimes and not-A at other times?
   - In space: can A be true in one place and not-A in another?
   - In condition: can A be true under condition X and not-A under condition Y?
   - In scale: can A be true at system level but not-A at component level?

4. **Generate solutions** for each applicable separation principle

5. **Cross-domain check:** How do other fields resolve this same contradiction type?

## Expected Output

Contradiction statement + separation analysis + solutions per principle.
