# Method: Brainwriting 6-3-5 (solo variant)

**Primitives used:** `generate`, `transform(build-on)`, `externalize`
**Best for:** Structured ideation with forced iteration, building on previous ideas
**Cognitive mode:** Flexibility → Persistence through iteration

## Solo Adaptation

1. **Round 1:** Generate 3 seed ideas for the problem
2. **Round 2:** For each seed idea, generate 3 variations/extensions/builds
3. **Round 3:** For each Round 2 idea, generate 3 more variations
4. After 3 rounds: 3 + 9 + 27 = 39 idea fragments (collapse duplicates — expect ~15-20 unique)
5. Cluster and evaluate

**Key rule:** Each round builds on the previous — no blank-slate generation. This forces persistence and elaboration.
