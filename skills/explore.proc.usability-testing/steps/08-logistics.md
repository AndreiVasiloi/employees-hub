# Step 8: Plan Logistics and Roles

## Objective

Define tools, responsibilities, and session checklists.

## Entry Criteria

- [ ] Step 7 (Moderation Guide) complete with human review

## Actions

### 8.1 Define Tools

- Video call (Zoom/Teams/Meet)
- Recording (tool and permissions)
- Note-taking (template or tool)
- Prototype (link and access)
- Analysis tools (Miro, Dovetail, etc.)

### 8.2 Assign Roles

- Moderator (leads session)
- Note-taker (captures quotes, behaviors, timestamps)
- Observer(s) (silent, limit to 2-3)
- Decision maker review (when they'll review findings)

### 8.3 Session Checklist

**Before**: Prototype tested, test accounts ready, consent handled, recording tested
**During**: Timebox tasks, capture key moments, avoid leading
**After**: Save recording, consolidate notes within 24 hours, tag issues by severity

**STOP**: Wait for human to confirm logistics.

## Exit Criteria

- [ ] Tools defined
- [ ] Roles assigned
- [ ] Session checklist created
- [ ] Human has confirmed logistics
