# Step 11: Validation

## Objective

Run a completeness check on the usability test plan.

## Entry Criteria

- [ ] Step 10 (Write Document) complete
- [ ] Document exists at `explore/design/usability-test-plan-[slug].md`

## Actions

### 11.1 Run Completeness Check

Verify all required elements:

- [ ] Clear objective, scope, and decisions to inform
- [ ] Participant profile and recruitment criteria defined
- [ ] 3 to 5 realistic tasks with measurable success criteria
- [ ] Data capture plan includes behavioral and qualitative signals
- [ ] Moderation guide includes intro, tasks, and wrap-up
- [ ] Analysis plan includes severity and deliverables
- [ ] Logistics and roles assigned
- [ ] Risks identified with mitigations

### 11.2 Present Validation Results

```
Usability Test Plan Complete

File: explore/design/usability-test-plan-[slug].md
Tasks: [N] tasks covering [N] flows
Participants: [N] participants, [profile]
Timeline: [Recruitment → Testing → Analysis dates]

Ready for stakeholder approval and recruitment.
```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Document ready for stakeholder approval
