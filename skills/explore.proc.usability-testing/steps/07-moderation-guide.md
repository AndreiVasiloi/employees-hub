# Step 7: Create Moderation Guide

## Objective

Write the session script including introduction, warm-up, task prompts, and wrap-up questions.

## Entry Criteria

- [ ] Step 6 (Metrics) complete with human confirmation

## Actions

### 7.1 Introduction Script

- Thank you and purpose
- Consent and recording
- "This is the product being tested, not you"
- Think aloud reminder
- Questions before we start

### 7.2 Warm-up Questions

Questions about current workflows, tools, and pain points.

### 7.3 Task Prompts

Use tasks from Step 5. After each task ask:
- "What were you expecting?"
- "What felt unclear?"
- "How confident are you?" (1-7 scale)

If participant gets stuck:
- Wait 10-15 seconds before prompting
- Use neutral prompts ("What are you thinking?")
- Avoid leading ("Did you see the button?")

### 7.4 Wrap-up Questions

- What stood out as most useful?
- What felt most confusing or risky?
- If you could change one thing?
- How likely to use in real work?

**STOP**: Wait for human to review moderation guide.

## Exit Criteria

- [ ] Introduction script written
- [ ] Warm-up questions defined
- [ ] Task prompts with follow-up questions
- [ ] Wrap-up questions defined
- [ ] Human has reviewed moderation guide
