# Step 4: Define Participant Profile and Recruitment

## Objective

Specify who to recruit, screening criteria, sample size, and recruitment approach.

## Entry Criteria

- [ ] Step 3 (Method) complete with human confirmation

## Actions

### 4.1 Define Target Profile

- Role or segment (from personas)
- Experience level (novice/intermediate/expert)
- Context of use (where/when they use the product)
- Devices (desktop/mobile/both)

### 4.2 Define Screening Criteria

- Must have characteristics
- Must not have (exclusions)

### 4.3 Define Sample Size

- 5-8 for directional testing
- 8-12 for variant comparison

### 4.4 Define Recruitment Approach

- Source (internal/external/panel/customer list)
- Incentive (if applicable)
- Timeline (recruitment start, testing dates, analysis complete)

**STOP**: Wait for human to confirm participant profile.

## Exit Criteria

- [ ] Target profile defined from personas
- [ ] Screening criteria documented
- [ ] Sample size determined
- [ ] Recruitment approach and timeline defined
- [ ] Human has confirmed participant profile
