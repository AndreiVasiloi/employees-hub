# Step 6: Define Metrics and Data Capture

## Objective

Specify what to measure — behavioral metrics, attitudinal metrics, and qualitative capture.

## Entry Criteria

- [ ] Step 5 (Scenarios and Tasks) complete with human validation

## Actions

### 6.1 Behavioral Metrics

- Task completion (success/partial/fail)
- Time on task (if meaningful)
- Error rate (critical vs non-critical)
- Path analysis (clicks, hesitations, backtracking)
- Assistance required (none/minor prompts/guided)

### 6.2 Attitudinal Metrics

- Single ease question after each task (1-7 scale)
- Confidence rating after each task (1-7 scale)
- Post-test satisfaction (SUS or custom questions)

### 6.3 Qualitative Capture

- Quotes tied to moments with timestamps
- Observed behaviors and confusion points
- Mental model statements and terminology used

**STOP**: Wait for human to confirm metrics.

## Exit Criteria

- [ ] Behavioral metrics defined
- [ ] Attitudinal metrics defined
- [ ] Qualitative capture plan documented
- [ ] Human has confirmed metrics
