# Step 3: Select Method and Format

## Objective

Choose the appropriate testing method based on objectives and constraints.

## Entry Criteria

- [ ] Step 2 (Research Questions) complete with human validation

## Actions

### 3.1 Select Study Type

Options:
- Moderated usability test (remote or in-person)
- Unmoderated usability test
- First-click test (for IA or entry points)
- Tree test (for findability and labeling)
- Intercept test (if testing live product)

Provide rationale for why this method is appropriate.

### 3.2 Define Format

- Session length (45-60 min moderated, 15-20 min unmoderated)
- Moderation style
- Location (remote/in-person)
- Recording (tools and permissions)

### 3.3 Define Stimulus

- Prototype link or artifact location
- Fidelity notes (what is clickable, faked, limited)

**STOP**: Wait for human to confirm method.

## Exit Criteria

- [ ] Study type selected with rationale
- [ ] Format defined (length, moderation, location, recording)
- [ ] Stimulus documented with fidelity notes
- [ ] Human has confirmed method
