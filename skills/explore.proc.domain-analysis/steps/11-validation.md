# Step 11: Validation

## Objective

Run a completeness check on the domain analysis document.

## Entry Criteria

- [ ] Step 10 (Write Document) complete
- [ ] Document exists at `explore/explore-[slug]/domain-analysis.md`

## Actions

### 11.1 Run Completeness Check

Verify all required sections:

- [ ] Domain glossary defines all key terms consistently
- [ ] Domain model includes all core entities with relationships
- [ ] Entity lifecycle states documented for key entities
- [ ] Business rules and constraints clearly stated
- [ ] User roles defined by domain responsibility (not org chart)
- [ ] Current state documented with pain points
- [ ] Domain risks and unknowns identified
- [ ] Domain model summary provides actionable insights
- [ ] Assumptions prioritized and tagged for validation

### 11.2 Present Validation Results

```

```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Document ready for downstream consumption
