# Step 9: Validation

## Objective

Run a completeness check on the hypothesis document.

## Entry Criteria

- [ ] Step 8 (Write Document) complete
- [ ] Document exists at `explore/explore-[slug]/hypothesis.md`

## Actions

### 9.1 Run Completeness Check

Verify all required elements:

- [ ] Hypothesis statement follows format
- [ ] Statement is specific (not vague)
- [ ] Evidence base documented with sources
- [ ] All evidence tagged [VALIDATED] or [ASSUMPTION]
- [ ] Assumptions identified with validation methods
- [ ] Success criteria are measurable
- [ ] Stakeholder validation recorded
- [ ] Status updated to STAKEHOLDER-VALIDATED

### 9.2 Present Validation Results

```
Hypothesis Documentation Complete

File: explore/explore-[slug]/hypothesis.md
Status: STAKEHOLDER-VALIDATED
Evidence Strength: [X]% validated
Confidence: [High/Medium/Low]
Critical Assumptions: [N] identified
Success Criteria: [N] metrics defined

Validation: [N] of [N] checks passed ✓

Ready for Solution Design (Step 3).
```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Document ready for downstream consumption
