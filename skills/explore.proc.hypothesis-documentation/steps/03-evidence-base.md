# Step 3: Document Evidence Base

## Objective

Link hypothesis to discovery evidence with source tracking and validation status.

## Entry Criteria

- [ ] Step 2 (Draft Hypothesis) complete with human approval

## Actions

### 3.1 Create Evidence Table

```
Evidence Base

| Evidence Type | Source | Key Finding | Validation Status |
|--------------|--------|-------------|------------------|
| User Need | Persona P1 | [Need statement] | [VALIDATED/ASSUMPTION] |
| Pain Point | Journey Map Stage 2 | [Pain description] | [VALIDATED/ASSUMPTION] |
| Opportunity | Journey Map | [Opportunity O1] | [VALIDATED/ASSUMPTION] |
| Business Value | Signal | [Why This Matters] | [VALIDATED/ASSUMPTION] |
| Domain Insight | Context | [Insight from domain model] | [VALIDATED/ASSUMPTION] |
```

### 3.2 Assess Evidence Strength

```
Strength of Evidence:
- [X]% validated (from stakeholder confirmation)
- [Y]% assumptions (need further validation)

Overall Confidence: [High/Medium/Low]
```

## Exit Criteria

- [ ] All evidence sources documented in table
- [ ] Each evidence item tagged [VALIDATED] or [ASSUMPTION]
- [ ] Evidence strength percentage calculated
- [ ] Overall confidence level assessed
