# Step 2: Draft Hypothesis Statement

## Objective

Create hypothesis using the standard format with specific users, evidence, and measurable signals.

## Entry Criteria

- [ ] Step 1 (Gather Evidence) complete

## Actions

### 2.1 Draft Hypothesis

Create hypothesis using standard format:

```
"We believe [specific user/persona] needs [capability/outcome] 
because [evidence from discovery]. 
We will know this is true when [measurable signal/metric]."
```

**Example**:
```
"We believe nurse practitioners need automated patient scheduling 
because manual scheduling causes 30% of their admin time and leads to 
patient dissatisfaction (evidence from journey map pain points). 
We will know this is true when scheduling time reduces by 50% and 
patient satisfaction scores increase by 20 points."
```

### 2.2 Human Checkpoint

Present hypothesis for review:
- Approve (hypothesis is clear and measurable)
- Revise (tell me what to change)
- Add evidence (tell me what's missing)

**STOP**: Wait for human to validate hypothesis statement.

## Exit Criteria

- [ ] Hypothesis follows standard format
- [ ] Specific user/persona named (not generic "users")
- [ ] Evidence from discovery cited
- [ ] Measurable success signal defined
- [ ] Human has approved hypothesis statement
