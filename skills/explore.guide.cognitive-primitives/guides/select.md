# Primitive: select(ideas, policy)

**What:** Choose which ideas to advance using portfolio thinking.

## Selection Policies

| Policy | When | Risk |
|--------|------|------|
| **Top-N by Score** | Feasibility is priority | Favors safe over novel |
| **Portfolio Mix** | Want optionality | 1 high-risk + 1 safe + 1 novel |
| **Impact x Effort Quadrant** | Need prioritization | Quick wins, big bets, fill-ins, drops |
| **User Resonance Check** | Sustained effort needed | Ask: "which excites you most?" |

## Output

Selected ideas with explicit rationale for selection policy used.
