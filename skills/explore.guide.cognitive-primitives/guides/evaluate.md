# Primitive: evaluate(ideas, criteria)

**What:** Structured appraisal with bias defenses.

## Protocol

1. **State criteria explicitly** from framing:
   - Impact, Feasibility, Novelty, Risk, Alignment

2. **Score in batches** — 3-5 ideas at a time. H/M/L on each criterion. Relative comparison within batch.

3. **Bias checks after scoring:**
   - Is highest-ranked also first generated? (anchoring flag)
   - Are all top ideas from same cluster? (fixation flag)
   - Would an outsider find top picks surprising? (novelty check)
   - Ranking familiar over impactful? (availability flag)

4. **Devil's advocate** for each top-3 idea:
   - Strongest argument against it
   - Scenario where it fails
   - Stakeholder who would hate it

**Template:** `templates/evaluation-matrix.md`

## Output

Evaluation matrix + bias check notes + shortlist with tradeoffs.
