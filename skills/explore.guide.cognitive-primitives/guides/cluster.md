# Primitive: cluster(ideas)

**What:** Group raw ideas by thematic affinity into named clusters.

## Protocol

1. Read all ideas without judging quality
2. Group by: mechanism similarity, problem space similarity, user/stakeholder similarity
3. Name each cluster with a **one-line thesis** (not just a topic label)
   - Bad: "AI-related ideas"
   - Good: "Ideas that delegate cognitive load to an AI co-pilot"
4. Flag ideas that don't fit any cluster (orphans — often most original)
5. Flag ideas that bridge two clusters (bridges — often most integrative)

## Output

Named clusters with member ideas + orphan ideas + bridge ideas.
