# Step 6: Define Flow-Level Accessibility Checks

## Objective

For each P0 flow, create a checkpoint list of accessibility requirements that must be met.

## Entry Criteria

- [ ] Step 5 (State and Messaging) complete with confirmed requirements
- [ ] P0 flows identified from Step 2

## Actions

### 6.1 Create Flow Checklists

For each P0 flow, create a checklist:

```
Flow-Level Accessibility Checks

For each P0 flow, I'll create a checklist:

**Flow: [Name]**
- [ ] Keyboard-only completion possible end-to-end
- [ ] All controls have accessible names
- [ ] Errors announced and recoverable
- [ ] Focus moves predictably between steps
- [ ] Confirmation/success announced
- [ ] [Flow-specific checks]

[Repeat for each flow]

Do these checklists cover the critical validation points?
```

**STOP**: Wait for human to validate flow checks.

## Exit Criteria

- [ ] Checklist created for each P0 flow
- [ ] Flow-specific checks included where needed
- [ ] Human validated flow checks
