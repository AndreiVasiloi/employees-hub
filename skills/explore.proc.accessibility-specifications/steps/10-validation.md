# Step 10: Validation

## Objective

Run a completeness check on the accessibility specification to ensure all required sections are present and properly documented.

## Entry Criteria

- [ ] Step 9 (Write Specification) complete with full document written
- [ ] Specification file exists at `explore/design/accessibility-[slug].md`

## Actions

### 10.1 Run Completeness Check

Verify all required sections are present and populated:

- [ ] Conformance target and test baseline defined
- [ ] Cross-cutting requirements cover structure, keyboard, forms, visual, content
- [ ] All components used in wireframes have specifications
- [ ] All states have accessibility requirements
- [ ] P0 flows have accessibility checklists
- [ ] Acceptance criteria are testable and clear
- [ ] Open questions and risks documented

### 10.2 Present Validation Results

```
Accessibility Specifications Complete

File: explore/design/accessibility-[slug].md
Conformance target: [WCAG version and level]
Components specified: [N] components
Flows covered: [N] P0 flows
Acceptance criteria: [N] testable criteria

Ready for design review and development handoff.
```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Specification ready for design review and development handoff
