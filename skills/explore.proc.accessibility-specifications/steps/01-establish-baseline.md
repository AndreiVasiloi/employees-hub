# Step 1: Establish Baseline Standard and Test Environment

## Objective

Define conformance target and testing approach for the accessibility specification.

## Entry Criteria

- Context baseline available (problem, domain, constraints)
- Wireframes available (screens and flows to specify)
- Target surfaces identified (web, mobile, or both)

## Actions

### 1.1 Define Conformance Target

Establish the accessibility standard:

```
Accessibility Baseline

I need to establish the accessibility baseline:

1. **Conformance target**:
   - Standard: [WCAG 2.1 / WCAG 2.2]
   - Level: [A / AA / AAA]
   - Default if not specified: WCAG 2.2 AA

2. **Platforms**:
   - [Web / iOS / Android / Multiple]

3. **Supported input methods**:
   - Keyboard: [Yes/No]
   - Touch: [Yes/No]
   - Screen reader: [Yes/No]
   - Voice control: [Yes/No]

4. **Assistive technology baseline** (minimum for testing):
   - Web: [e.g., "Keyboard-only plus NVDA on Chrome"]
   - Mobile: [e.g., "VoiceOver on iOS, TalkBack on Android"]

5. **Supported browsers** (if web):
   - [Chrome, Firefox, Safari, Edge - specify versions if critical]

Please confirm this baseline or provide corrections.
```

**STOP**: Wait for human to confirm baseline.

## Exit Criteria

- [ ] Conformance target defined (WCAG version and level)
- [ ] Target platforms identified
- [ ] Supported input methods documented
- [ ] Assistive technology baseline established
- [ ] Supported browsers listed (if web)
- [ ] Human confirmed baseline
