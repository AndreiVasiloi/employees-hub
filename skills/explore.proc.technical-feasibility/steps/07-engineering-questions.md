# Step 7: Generate Questions for Engineering

## Objective

Create targeted questions to validate assumptions, organized by category with rationale and owner.

## Entry Criteria

- [ ] Step 6 (Design Guardrails) complete

## Actions

### 7.1 Generate Questions by Category

For each question, document:
- The question
- Why we need to know (impact on design)
- Who to ask (team/person)
- Priority (High/Medium/Low)

**Categories**:
- System context questions (existing systems, integrations)
- Data questions (availability, quality, latency)
- Performance questions (requirements, scalability)
- Feasibility questions (technical feasibility, effort)
- Integration questions (API capabilities, data sync)
- Timeline questions (delivery timeline, dependencies)

### 7.2 Prioritize Questions

Order questions by priority, focusing on those that block design decisions.

## Exit Criteria

- [ ] Questions generated across all categories
- [ ] Each question has rationale and owner
- [ ] Questions prioritized
- [ ] High-priority questions highlighted
