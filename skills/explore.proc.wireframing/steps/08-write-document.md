# Step 8: Write Wireframe Document

## Objective

Write the complete wireframe document to `explore/design/wireframes-[slug].md`.

## Entry Criteria

- [ ] Step 7 (Open Questions) complete with human input

## Actions

### 8.1 Write Document

Write complete document to `explore/design/wireframes-[slug].md`.

**Use template**: `templates/wireframe-template.md`

**Required sections**:
1. Snapshot (objective, inputs, output, fidelity rules, assumptions)
2. Users and Top Tasks
3. Scope and Constraints
4. Information Architecture Alignment
5. Key Flows (with edge cases)
6. Screen Inventory (P0/P1/P2)
7. Wireframe Conventions
8. Screen Specs (one per screen)
9. Cross-Screen Patterns
10. Validation Checklist
11. Open Questions and Decisions Needed
12. Next Steps
13. Acceptance Criteria

### 8.2 Verify Document

Confirm all 13 sections present with no placeholder text remaining.

## Exit Criteria

- [ ] Document written to `explore/design/wireframes-[slug].md`
- [ ] All 13 sections present and populated
- [ ] No placeholder text remaining
