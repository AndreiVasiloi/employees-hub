# Step 5: Document Key Flows

## Objective

For each key flow, document the screen-to-screen journey with entry points, steps, success outcome, and edge cases.

## Entry Criteria

- [ ] Step 4 (Wireframe Screens) complete with human review

## Actions

### 5.1 Document Each Flow

For each key flow:
- **Purpose** — what the flow accomplishes
- **Entry points** — where users start
- **Steps** — screen-to-screen sequence
- **Success outcome** — what happens on completion

### 5.2 Define Edge Cases Per Flow

- **No data** — how handled
- **Validation failure** — how handled
- **Permission denied** — how handled
- **System error** — how handled

**STOP**: Wait for human to validate each flow.

## Exit Criteria

- [ ] All key flows documented with steps
- [ ] Edge cases defined for each flow
- [ ] Human has validated flows
