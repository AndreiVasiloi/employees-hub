# Step 6: Define Cross-Screen Patterns

## Objective

Document patterns that should be consistent across all screens.

## Entry Criteria

- [ ] Step 5 (Document Flows) complete with human validation

## Actions

### 6.1 Define Patterns

- **Navigation** — how users move between screens, back button, breadcrumbs
- **Forms and validation** — inline vs summary, error placement, required fields
- **Feedback and messaging** — toast vs banner vs modal, success/error patterns
- **Tables and lists** — pagination, sorting, filters
- **Search** — scope, default behavior, no results
- **Permissions** — what changes by role

**STOP**: Wait for human to validate patterns.

## Exit Criteria

- [ ] All cross-screen patterns documented
- [ ] Patterns consistent with IA and user expectations
- [ ] Human has validated patterns
