# Step 9: Validation

## Objective

Run a completeness check on the wireframe document.

## Entry Criteria

- [ ] Step 8 (Write Document) complete
- [ ] Document exists at `explore/design/wireframes-[slug].md`

## Actions

### 9.1 Run Completeness Check

Verify all required elements:

- [ ] All P0 flows have start-to-finish coverage
- [ ] Edge cases are defined for each critical screen
- [ ] Screen inventory matches scope
- [ ] Each screen has a single clear primary action
- [ ] Labels are consistent with IA assumptions
- [ ] Navigation is predictable and reversible
- [ ] Data needs are realistic or flagged as assumptions
- [ ] Dependencies and constraints are captured
- [ ] Permissions are not an afterthought
- [ ] Open questions are explicit
- [ ] Proposed test tasks can be derived from the flows

### 9.2 Present Validation Results

```
Wireframes Complete

File: explore/design/wireframes-[slug].md
Screens: [N] P0, [N] P1, [N] P2
Flows: [N] documented with edge cases
Open questions: [N] prioritized

Coverage:
✓ All P0 screens documented
✓ All critical flows covered
✓ Edge cases defined
✓ Patterns documented

Ready for stakeholder review and usability testing.
```

## Exit Criteria

- [ ] All completeness checks pass
- [ ] Validation results presented to human
- [ ] Document ready for stakeholder review
