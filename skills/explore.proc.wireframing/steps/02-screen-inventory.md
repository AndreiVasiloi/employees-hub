# Step 2: Create Screen Inventory

## Objective

Based on IA and flows, propose a complete screen list prioritized as P0, P1, and P2.

## Entry Criteria

- [ ] Step 1 (Review Scope) complete with human confirmation

## Actions

### 2.1 Propose Screen Inventory

**P0 (Must have — critical path)**:
- Screens required for core flows to work

**P1 (Should have — important but not blocking)**:
- Screens that support important but non-critical functionality

**P2 (Later — nice to have)**:
- Power user features, advanced views

### 2.2 Present for Validation

List each screen with its purpose and priority level. Include total counts.

**STOP**: Wait for human to validate screen inventory.

## Exit Criteria

- [ ] Screen inventory proposed with P0/P1/P2 priorities
- [ ] Each screen has a clear purpose
- [ ] Human has validated the inventory
