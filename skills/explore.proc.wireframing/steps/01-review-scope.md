# Step 1: Review Inputs and Identify Scope

## Objective

Review all inputs to understand primary users, target surfaces, must-have flows, scope boundaries, and known constraints.

## Entry Criteria

- [ ] Context baseline available
- [ ] Information Architecture available (or flagged as risk)
- [ ] Personas available
- [ ] Journey maps and user flows available
- [ ] Slug confirmed

## Actions

### 1.1 Identify Primary Users and Top Tasks

From personas and journeys, list:
- User groups and their top tasks
- Context of use (where/when/how)

### 1.2 Define Target Surfaces

- Web (desktop/responsive)?
- Mobile (native/web)?
- Breakpoints to consider?

### 1.3 Identify Must-Have Flows or Screens

From IA and user flows, list the critical flows/screens.

### 1.4 Define Scope

- In scope: what we're wireframing
- Out of scope: what we're not wireframing

### 1.5 Document Known Constraints

- Technical, content, compliance, business constraints

**STOP**: Wait for human to confirm scope.

## Exit Criteria

- [ ] Primary users and top tasks identified
- [ ] Target surfaces defined
- [ ] Must-have flows listed
- [ ] In/out of scope defined
- [ ] Constraints documented
- [ ] Human has confirmed scope
