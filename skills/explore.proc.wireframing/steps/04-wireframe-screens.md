# Step 4: Wireframe Each P0 Screen

## Objective

For each P0 screen, create a detailed wireframe spec covering purpose, actions, layout, components, content, data, interactions, states, and accessibility.

## Entry Criteria

- [ ] Step 3 (Conventions) complete with human confirmation

## Actions

### 4.1 For Each P0 Screen, Document:

1. **Purpose** — what this screen accomplishes
2. **Primary and secondary actions**
3. **Layout** — header, main, side, footer content
4. **Components** — each component and its purpose
5. **Content blocks** — placeholder copy intent
6. **Data needs** — entities, fields, source
7. **Interaction notes** — numbered behaviors
8. **States**:
   - Empty (what user sees, recommended CTA)
   - Loading (skeleton/spinner, what remains usable)
   - Error (message type, recovery)
   - No permission (message, next step)
   - Offline (fallback, if relevant)
9. **Accessibility notes** — focus order, keyboard behavior, labels, screen reader announcements
10. **Open questions** — anything needing resolution

### 4.2 Ask for Missing Information

For each screen, if information is available from context/IA/flows, propose answers. If missing, ask specific questions.

**STOP**: After each screen, wait for human to review before moving to the next.

## Exit Criteria

- [ ] All P0 screens wireframed with full detail
- [ ] Human has reviewed each screen
- [ ] All states documented per screen
