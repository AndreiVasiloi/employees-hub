# Step 2: Gather Flow Parameters

## Objective

For each flow in the set, gather detailed parameters. Complete all questions for F1 before starting F2.

## Entry Criteria

- [ ] Step 1 (Identify Flows) complete with human input

## Actions

### 2.1 Gather Parameters Per Flow

For each flow, collect:

1. **Task Objective** - What is the user trying to accomplish? (one clear goal)
2. **Entry Point** - Where does this flow start? (e.g., landing page, dashboard, notification)
3. **Exit Point** - What is the successful completion state?
4. **Persona** - Which persona is performing this task? (reference persona ID)
5. **Journey Context** - Does this flow relate to a specific journey? (reference journey ID)
6. **Decision Points** - Are there any conditional branches?
7. **Loops** - Are there any repeat steps? (e.g., "Retry on error")
8. **Detail Level** - Abstract (goal-level) or Specific (screen-level)?

Tag items as `[VALIDATED]` if human confirms, or `[ASSUMPTION]` if inferred.

**STOP**: Wait for human input for each flow.

## Exit Criteria

- [ ] All flow parameters gathered
- [ ] Each parameter tagged as [VALIDATED] or [ASSUMPTION]
- [ ] Human has provided input for each flow
