# Step 6: Present Flows for Human Validation

## Objective

Present each flow with validation status and top assumptions for human review.

## Entry Criteria

- [ ] Step 5 (UX Validation) complete — all flows pass

## Actions

### 6.1 Present Each Flow

For each flow:

```
Flow [N]: [Title]

Objective: [Task goal]
Entry: [Starting point]
Exit: [Success state]
Steps: [N] total ([X] validated, [Y] assumptions)

Validation Priority: [High/Medium/Low]
- High = >50% assumptions
- Medium = 25-50% assumptions
- Low = <25% assumptions

Top assumptions to validate:
1. [Assumption 1]
2. [Assumption 2]

Review this flow:
- Approve (flow is accurate)
- Correct (tell me what to change)
- Add step (tell me what's missing)
```

**STOP**: Wait for human validation of each flow.

### 6.2 Apply Changes (if needed)

If human requests corrections, update flow and re-validate.

## Exit Criteria

- [ ] All flows presented to human
- [ ] Human has approved or corrected each flow
- [ ] Any changes applied and re-validated
