## Actions

### 8.1 Write Document

Write complete flow set to `explore/domain/flows-[slug].md`.

**Use template**: `templates/flow-template.md`

**File structure**:
1. YAML frontmatter (version, created, source, product_context, flow_count, persona/journey refs, status)
2. Agent Usage Instructions (including Shape Legend)
3. One section per flow (F1, F2, etc.) with:

   - Narrative Task Flow

4. Validation Summary table
