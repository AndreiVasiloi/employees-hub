# Step 1: Identify Flow Count & Scope

## Objective

Establish the full scope of the flow set before collecting any flow data.

## Entry Criteria

- [ ] Personas available
- [ ] Journey maps available
- [ ] HLD available
- [ ] Slug confirmed

## Actions

### 1.1 Ask for Flow Count and Scope

Ask the human:

```
How many user flows do you need to define for this product or context?
- Provide the number and briefly describe each flow's task objective
- Example: "3 flows: 1) Sign up, 2) First purchase, 3) Password reset"
```

**STOP**: Wait for human to specify flow count and task objectives.

## Exit Criteria

- [ ] Flow count confirmed
- [ ] Task objectives listed for each flow
- [ ] Human has provided flow scope
